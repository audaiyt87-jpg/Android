# تحويل محفظة الذهب من EXE إلى تطبيق أندرويد (APK)

## لماذا لا يمكن تحويل الـ EXE مباشرة؟
التطبيق القديم مكتوب بـ **Tkinter**، وهذه المكتبة **لا تعمل على الأندرويد إطلاقاً**.
لذلك أعدت بناء نفس التطبيق بمكتبة **Kivy** (التي تعمل على الأندرويد)، مع الحفاظ على كل المزايا:
- شراء/أمر بيع بالغرام مع خصم FIFO والربح المحقق.
- فروق سعر الشراء/البيع (الراجحي) وتثبيت سعر البيع.
- عملات USD / SAR / AED.
- سجل العمليات + حاسبة الزكاة (نصاب 85غ، 2.5%) + مخطط سعر الغرام خلال 24 ساعة.
- تنبيه عند بلوغ سعر معيّن.

وبما أنك لا تملك جهاز تطوير، نبني الـ **APK عبر GitHub Actions** بالضبط كما فعلنا مع الـ EXE.

---

## محتوى الحزمة
```
GoldPortfolioAndroid/
├─ main.py                         كود التطبيق (Kivy)
├─ buildozer.spec                  إعدادات بناء الأندرويد
├─ .github/workflows/build-apk.yml بناء الـ APK على GitHub
├─ assets/                         مكان الخط العربي (مهم — اقرأ بالأسفل)
└─ README_Android.md               هذا الملف
```

---

## خطوة مهمة قبل البناء: الخط العربي
لكي تظهر الحروف العربية متصلة بشكل صحيح، يجب إضافة ملف خط عربي:
1. حمّل خطاً عربياً مجانياً مثل **Noto Naskh Arabic** من Google Fonts.
2. ضع الملف داخل مجلد `assets/` باسم: `NotoNaskhArabic-Regular.ttf`
   (أو `Amiri-Regular.ttf` — الكود يتعرّف على الاثنين).

> إن لم تضع خطاً سيعمل التطبيق لكن قد تظهر الحروف العربية غير متصلة.

---

## خطوات البناء عبر GitHub Actions (خطوة بخطوة)

1. ادخل على مستودعك على GitHub (نفس المستودع الذي بنيت فيه الـ EXE أو مستودع جديد).
2. ارفع كل ملفات هذه الحزمة:
   - اضغط **Add file ← Upload files**.
   - اسحب `main.py` و `buildozer.spec` و `README_Android.md` ومجلد `assets` (مع الخط).
   - لملف الـ workflow: اضغط **Add file ← Create new file** واكتب المسار بالضبط:
     `.github/workflows/build-apk.yml` ثم الصق محتوى الملف.
   - اضغط **Commit changes**.
3. افتح تبويب **Actions** في أعلى المستودع.
4. اختر workflow باسم **Build Android APK** من اليسار.
5. اضغط **Run workflow ← Run workflow** (الزر الأخضر).
6. انتظر انتهاء البناء. **ملاحظة:** أول بناء للأندرويد يستغرق
   عادة **20–40 دقيقة** (يحمّل Android SDK/NDK). البناءات التالية أسرع.
7. بعد ظهور العلامة الخضراء ✓: ادخل على الـ run ثم انزل لأسفل إلى قسم **Artifacts**.
8. نزّل **GoldPortfolio-Android-APK** — بداخله ملف `.apk`.

---

## تثبيت الـ APK على هاتفك
1. انقل ملف `.apk` إلى هاتفك (أو حمّله مباشرة عليه).
2. افتح الملف؛ سيطلب منك السماح بـ **تثبيت من مصادر غير معروفة** — وافق.
3. اضغط تثبيت. هذا طبيعي لأن التطبيق غير موقّع من Google Play (مثل SmartScreen في الـ EXE).

الـ APK الناتج هو نسخة **debug** وهي كافية للاستخدام الشخصي.
لنشره على Google Play تحتاج نسخة **release** موقّعة (يمكن إضافتها لاحقاً).

## ملاحظات تقنية
- تُحفظ البيانات (الدفعات/السجل/الأسعار) تلقائياً في ملف JSON داخل تخزين التطبيق.
- تم التحقق من الكود بـ `py_compile` (لا توجد شاشة لاختبار الواجهة بصرياً هنا).
- المخطط مرسوم داخلياً بـ Kivy Canvas بدون مكتبات ثقيلة.
- يمكنك تعديل أسعار الصرف (USD/AED) من ثابت `CURRENCIES` في أعلى `main.py`.
